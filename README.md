
# Retail Sales & Customer Analytics Using Python

##  Project Overview

* Analyzed retail transaction data using Python.
* Performed data cleaning and exploratory data analysis (EDA).
* Analyzed sales, profit, customers, products, categories, and regions.
* Created visualizations to identify trends and business patterns.
* Generated data-driven business insights and recommendations.

##  Business Objectives

* Calculate total sales and profit.
* Analyze monthly sales trends.
* Identify the best-performing categories and sub-categories.
* Identify the top-performing products.
* Analyze customer segments and high-value customers.
* Identify regions with the highest sales.
* Analyze the relationship between sales, discount, and profit.
* Identify products with high sales but low profitability.

##  Technologies Used

* **Python**
* **Pandas** – Data cleaning and data manipulation
* **NumPy** – Numerical analysis
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Jupyter Notebook** – Analysis and documentation
